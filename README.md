# Curso Gratis de IA desde Cero — videos

Videos terminados del **Curso Gratis de IA desde Cero** (canal de YouTube *SM Dev | Curso Gratis de IA y Apps* y TikTok *@aiagentsacademy*).

Este repositorio solo aloja los mp4 para que tengan un enlace público directo que vidIQ pueda importar al preparar la publicación. No hay código aquí.

## Cómo funciona

1. La tarea nocturna produce las lecciones y sube cada mp4 a `videos/` con el nombre `curso-ia-leccion-N-<tema>.mp4`.
2. Su paquete de publicación (.txt) va a la carpeta de Drive *Curso IA - Para publicar*, con una primera línea `VIDEO_URL:` que apunta al mp4 de aquí.
3. La tarea de publicación lee esa línea, importa el video en vidIQ y prepara los borradores para YouTube y TikTok, que Santo aprueba con "publica".

Los videos se quedan en `videos/` aunque ya estén publicados, para que los enlaces nunca se rompan.

Enlace directo de cada video:

```
https://raw.githubusercontent.com/santo29/curso-ia-videos/main/videos/<archivo>.mp4
```
